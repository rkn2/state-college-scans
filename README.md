# State College scan coverage

Public snapshot of which State College historic buildings have an exterior backpack laser scan, drone roof views and
Sanborn map matches, by HARB priority area. Heritage 3D Lab, Penn State Architectural Engineering, with the State
College Borough Historical and Architectural Review Board.

Live page: https://rkn2.github.io/state-college-scans/

Building data comes from Borough of State College GIS (contributing properties, historic districts, draft zoning
areas, 1982 county survey), with owner and sale fields removed. The page is refreshed from the lab's working dashboard
as work goes on.

Historic Sanborn fire insurance maps (1906, 1911, 1922, 1929) can be switched on under the buildings. They are the
georeferenced mosaics from the Penn State University Libraries' Donald W. Hamer Center for Maps and Geospatial
Information, loaded live from its ArcGIS tile services. Sheet numbers and scan links for West End buildings come from
the lab's Sanborn index. Basemap Esri.

Aerial photos are Nearmap vertical imagery from August 29, 2026 and April 19, 2023 (leaf-off), downloaded as tiles over
the four areas and served from this repo so no API key is used on the page. Imagery &copy; Nearmap, published with the
lab's approval.
