# State College scan coverage

Public snapshot of which State College historic buildings have an exterior backpack laser scan, drone roof views and
Sanborn map matches, by HARB priority area. Heritage 3D Lab, Penn State Architectural Engineering, with the State
College Borough Historical and Architectural Review Board.

Live page: https://rkn2.github.io/state-college-scans/

Building data comes from Borough of State College GIS (contributing properties, historic districts, draft zoning
areas, 1982 county survey), with owner and sale fields removed. The page is refreshed from the lab's working dashboard
as work goes on.
